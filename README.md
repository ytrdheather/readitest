# 리디테스트 (Readitest)

> **이어서 작업하려면 [`HANDOFF.md`](HANDOFF.md) 부터 읽으십시오.**

리디튜드 학원 **내신 마스터** — 원장이 승인한 문항만 담긴 은행에서, 강사가 학생을 고르면
학교·범위에 맞는 내신 학습지가 나오는 **조립기**.

- 진행 상황 → [`STATUS.md`](STATUS.md)
- 설계 전체 → [`docs/리디테스트_기획서_v0.1.md`](docs/리디테스트_기획서_v0.1.md)
- 상위 문서 → 「리디튜드 학원 정비 및 내신 마스터 구축 계획」(2026)

이 프로그램이 답해야 하는 단 하나의 질문:
**「내신대비를 원장 없이 한 시즌 돌릴 수 있는가.」**

## ⚠️ 이 저장소는 반드시 Private 입니다

**Public으로 전환하거나 협업자를 추가하기 전에 반드시 아래를 다시 검토하십시오.**

### 저작권

`data/` 안에 학교 배부 프린트와 외부지문의 **본문 전문**이 들어 있습니다.
교과서·기출·학교 배부물은 저작권 대상이며, 시험지에는 전재·복제 금지가 명시돼 있습니다.

- **학원 내부 지도용**과 **외부 배포·상품화**는 다릅니다 (상위 계획서 8장)
- Private 저장소는 내부 보관에 가깝지만, 공개·공유 시점에는 성격이 바뀝니다
- 상품화 검토 시에는 **지문에 의존하지 않는 문항**(포인트 단위 훈련)만 분리할 수 있도록
  태깅 구조를 유지하고 있습니다

### 개인정보

- 스캔 원본에는 학생 이름·반·번호·손글씨가 있습니다 → **저장소에 넣지 않습니다.**
  원본은 학원 네트워크 드라이브(`Z:`)에만 둡니다
- `.gitignore`가 `*.pdf` / `*.png` / `data/scans/`를 막고 있습니다

### 키

`.env`는 `.gitignore`로 제외됩니다. **키를 커밋하지 마십시오.**
값이 필요하면 각 서비스 콘솔에서 새로 발급받으십시오.

## 구성

```
docs/     설계 문서 (기획서)
db/       Supabase 스키마 SQL, 인제스트
tools/    점검 스크립트
data/     0단계 산출물 (지문·태깅·문항·검수결과·대조)
```

## 점검

```bash
python tools/check_env.py      # 키 4개 연결 확인 (값은 출력하지 않음)
python tools/check_schema.py   # 테이블 18개 + 마스터 시드 확인
```

## 다른 컴퓨터에서 이어서 작업할 때

1. 저장소를 clone
2. `.env`를 **직접 만들기** — 저장소에 없습니다. 형식은 `tools/check_env.py` 상단 참조
3. `python tools/check_env.py` 로 확인
4. 스캔 원본은 `Z:` 드라이브에서 직접 읽습니다 (저장소에 없음)
