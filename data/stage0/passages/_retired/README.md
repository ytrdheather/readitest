# 물러난 지문 레코드

지우지 않고 여기 둔다. **왜 물러났는지**를 남겨야 나중에 같은 실수를 반복하지 않는다.

2026-09-05 · 원장이 지정한 새 분류로 L5·L6 을 다시 만들면서 물러났다.

| 파일 | 물러난 이유 |
|---|---|
| `..._L5_본문1` ~ `본문4` | **제목이 없었다.** 5과 본문은 「Street Art in London」 하나이고 문단이 넷일 뿐인데, 제목 없는 지문 4개로 쪼개져 있었다. → `L5_StreetArtinLondon1~4` 로 대체 |
| `..._L5_GettingtoSebitPark` | 새 `L5 대화-7` (Watch and Talk C, 11발화) 과 **같은 대화**다. 대화문을 9개 전부 뽑으면서 중복이 됐다 |
| `..._L6_RecommendingaPerson` | 새 `L6 대화-5` (Watch and Talk C, 9발화) 와 **같은 대화**. 위와 같은 이유 |

물러난 계기는 원장의 지적이다 — 「지금 5과는 쓸데없이 나눠져있고. 6과는 또 잘 되어있고」.
5과 대화문은 9개 중 1개만 뽑혀 있었다.

## 새 분류 (원장 지정 2026-09-05)

| | 종류 | 이름 규칙 |
|---|---|---|
| 1 | 대화문 | `L{과} 대화-{순번}` · 의사소통 기능은 **이름이 아니라 속성**(`functions`)으로 |
| 2 | 본문 | `{제목}-{문단번호}` |
| 3 | Read More | 교과서 추가자료 `ReadMore-{n}` · 학교별 배부 외부지문은 `handout_external` |

대화문 이름을 기능으로 나누지 않는 이유: **거의 모든 대화가 기능 둘을 한 세트로 쓴다.**
L5 는 9개 중 6개가 「교통수단 + 소요시간」을 같이 쓴다. 기능으로 이름을 나누면 한쪽으로 몰리고
억지가 된다. 속성으로 두면 「이 기능만 연습」으로 골라 쓸 수 있다.
