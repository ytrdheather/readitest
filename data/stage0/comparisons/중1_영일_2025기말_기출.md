## 2. 그릇 — 영덕중1과 무엇이 다른가

| | **영일중1** | 영덕중1 |
|---|---|---|
| 선택/논술 | **20 / 4 (각 5점 = 20점)** | 17 / 4 (4·4·6·6) |
| 어휘 | 영영풀이 **2문항 8점** (6번 «아닌 것» · 17번 «찾을 수 없는 것») | 십자말 5점 + 공통 빈칸 3점 |
| **단문 나열형** | **3문항 13점** (3·5·9·12번 중 3·5·9·12 = 실제 4문항 16점) | **0** |
| 교사 자작 지문 | **3개** (1번 Foley · 13번 Global warming · 14번 경찰관) | 2개 |
| 어법 그릇 | **<보기> 단문 5개 나열 + 본문 밑줄 + 본문 괄호 조합** | 본문 괄호 + 밑줄 |
| T-FORM-CHOICE | **2문항** (15·19번 — 둘 다 ⓐⓑⓒ 조합) | 1문항 |
| 「개수 세기」 문항 | **3문항** (16·18·20번) | 0 |
| 논술 | **조건 영작 4개 · 단어 수 지정** (5 / 8~9 / 4 / 5~8) | 조건 영작 · Q&A · 비교급 표 · 고치기 |
| 외부지문 | **없음** (2025 기말 기준) | 없음 |

**핵심 차이 셋**

1. **단문 나열형이 16점.** 영덕은 0인데 영일은 <보기> a~e 5문장을 늘어놓고 「어법상 옳지 않은 것만」 「쓰임이 다른 하나」 「생략할 수 있는 것만」을 묻는다. 청명중2의 단문 나열형(20점)과 같은 성격이다.
2. **「개수 세기」가 3문항 14점.** <보기> 6~7문장을 주고 일치하는 **개수**를 묻는다 (①2개 ②3개 …). 한 문항 안에서 7문장을 다 따져야 해서 실질 난이도가 높다.
3. **T-FORM-CHOICE가 2문항.** 본문 안 ⓐⓑⓒ 괄호 조합을 두 번 낸다 (15번 L7 · 19번 L5). 중2는 네 학교가 딱 1개씩이었는데 중1 영일은 2개다.
