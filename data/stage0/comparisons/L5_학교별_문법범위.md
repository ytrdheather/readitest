# 5과 문법 — 학교마다 어디까지 다루는가

> 2026-09-07. 원장 지적에서 출발했다.
>
> 「학교마다 같은 문법 포인트를 다룬다고 하더라도, **선생이 나누어주는 학습지마다
> 동일한 문법 포인트를 커버하는 범위가 약간씩 미묘하게 달라.**」
>
> 클로드는 이걸 못 봤다. 문항을 `grammar_point` 코드에만 붙이고 **그 안의 범위**를
> 보지 않았다. 그래서 `school_grammar_map` 28행이 네 학교를 다 「수동태」로 같게
> 보이게 만든다. 배부 학습지를 열어 확인한 결과가 아래다.

## 영일중 — 목적격 관계대명사를 **깊게** 판다

`Grammar Help! | Lesson 5 (P. 94) 목적격 관계대명사` (배부물 3~4쪽)

| 구간 | 다루는 것 |
|---|---|
| [1] | 관계대명사 개념 · 두 문장을 잇는 대명사 역할 |
| [2] | 목적격 관계대명사 정의 · 선행사별 표 (사람 who/that · 사물 which/that · 모두 that) |
| [3] | **핵심 규칙 & 실전 판별법** |

[3]에서 나가는 범위가 넓다.

1. **생략** — 목적격 관계대명사는 단독으로 생략. `The movie (which/that) Tom watched yesterday was fun.`
2. **판별법** — `[명사 + 주어(S) + 동사(V)]` 가 이어지면 그 사이에 목적격이 생략된 것
3. 본문 연결 — `messages from people [(who/that) he meets] on the street`
4. **선행사가 something / anything / all / 최상급이면 `that`만** — who ✗ · 생략 ✗
5. **전치사 + 관계대명사** — `the bus for which we were waiting` (O) / `for that` (**X**)
6. **전치사 + who (X) · 전치사 + whom (O)**

연습문제 A 5문항은 전부 **「목적격 관계대명사 뒤 목적어 중복」** 을 친다.

> the pizza which I bought ~~it~~ / the teacher who we like ~~him~~ /
> the girl who I talked to ~~her~~

## 태장중 — 같은 포인트인데 **다른 데를** 판다

`Lesson 5 [목적격 관계대명사] Exercise A` 8문항 + `Worksheet No. 5-2 Grammar - Used to`

**Exercise A 가 묻는 것**

| 문항 | 무엇을 |
|---|---|
| 1·2 | 선행사별 who/whom/which/that 고르기 (2번은 「들어갈 수 있는 것 **모두**」) |
| 3·4·5 | 어법상 틀린 것 / `which` 를 쓸 수 **없는** 것 / 틀린 부분 고치기 |
| 6 | 밑줄을 **생략할 수 없는** 것 |
| 7 | **밑줄 친 `that` 의 쓰임이 나머지와 다른 것** ← 관계대명사 that vs 접속사 that |
| 8 | 단어 배열 (whom 포함) |

## 🔴 두 학교를 겹쳐 보면

| | 영일 | 태장 |
|---|---|---|
| 목적격 관계대명사 기본 · 선행사별 선택 | ○ | ○ |
| 생략 | ○ | ○ |
| whom | ○ | ○ |
| **목적어 중복 금지** | **○ (연습문제 전부)** | ○ (문항 5) |
| **선행사 something/all/최상급 → that** | **○** | ✗ |
| **전치사 + 관계대명사** (`for which` / `for that` 불가) | **○** | ✗ |
| **that 의 쓰임 구별** (관계대명사 vs 접속사) | ✗ | **○ (문항 7)** |
| **`used to` 계열** | ✗ | **○ (별도 워크시트 5-2)** |

**원장 말이 맞다.** 그런데 예상보다 차이가 크다 — 「미묘하게」가 아니라 **아예 다른
갈래를 파기도 한다.**

- 영일 아이에게 `that` 의 쓰임 구별을 물으면 안 배운 것이다.
- 태장 아이에게 `for which` 를 물으면 안 배운 것이다.
- **태장은 `used to` 를 별도 워크시트로 다룬다.** 교과서 5과 공식 문법이 아닌데,
  본문에 나오기 때문이다 (`Poor workers **used to** live in this area…`).
  used to + 동사원형 / There used to be / be used to + -ing / 부정문·의문문
  (didn't use to · Did you use to) / get used to + -ing — **다섯 갈래 전부.**

## 🔴 마스터에 담을 코드가 없다

5과 교과서 문법인데 `grammar_point` 31종에 대응 코드가 없다.

| 필요한 것 | 지금 있는 것과 무엇이 다른가 |
|---|---|
| **목적격 관계대명사** (생략 · 목적어 중복 · whom · 전치사+관계대명사) | `REL_PRON_VS_ADV` 는 관계대명사 vs 관계**부사** 구별이라 다른 현상. `REL_WHAT_VS_THAT` 도 다르다 |
| **`used to` 계열** (used to / be used to / get used to) | `VERB_MODAL_USAGE` 는 have to·must 라 다르다 |
| **지각동사 + 목적보어** (-ing / 동사원형) — L6 문법 | `SENSE_VERB_ADJ` 는 감각동사 + **형용사** 보어라 다르다 |

지금 L5·L6 지문 태그에서 관계대명사가 `REL_PRON_VS_ADV` 로 13개 붙어 있는데,
**담을 칸이 없어 가장 가까운 데로 간 것**일 수 있다. 승인되면 다시 태깅해야 한다.

## 그래서 `school_grammar_map` 에 무엇을 더해야 하나

포인트 코드를 잘게 쪼개는 것은 반대한다 — 31종이 100종이 되면 태깅 프롬프트가
부풀고 관리가 무너진다. 대신 **범위를 관측으로 적는다.** 이미 배운 원칙이다 —
「관측에는 범위를 함께 적는다」 (기획서 §5.5.9 정정).

    school_grammar_map
      영일중 · L5 · REL_OBJECT
        scope_note   생략 · 목적어 중복 · something/all/최상급→that · 전치사+관계대명사 · whom
        evidence     배부물 「Grammar Help! Lesson 5 (P.94)」 [3] · 연습문제 A 5문항
      태장중 · L5 · REL_OBJECT
        scope_note   생략 · 목적어 중복 · whom · that 쓰임 구별. 전치사+관계대명사는 안 다룸
        evidence     배부물 「Lesson 5 [목적격 관계대명사] Exercise A」 8문항
